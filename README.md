## Installations

<br />
## If you receive and error while installation below::

> run composer update instead of composer install
> also run php artisan key:generate

## 1. Clone the repository

> https://github.com/Umee7/joblister.git

<br />

## 2. Set the basic config

> Edit example.env to .env <br />
> Put your db username and password here with DB_DATABASE=job_lister. <br />
> ''' <br />

    DB_CONNECTION=mysql <br />
    DB_HOST=127.0.0.1 <br />
    DB_PORT=3306 <br />
    DB_DATABASE=job_lister <br /> !important
    DB_USERNAME=root <br />
    DB_PASSWORD= <br />

'''
<br />

## 3. Install Dependencies

> ~composer install <br />
> ~npm install <br />
> ~npm run dev
> <br />

## 4. Migrate Database

> ~php artisan migrate:fresh <br />
> ~php artisan db:seed <br /> > <br />

## 5. Serve application

> ~php artisan serve <br />

## About This Project

**Job Portal** is a modern Laravel-based web application for job seekers and employers. It features a clean UI, secure authentication, and a robust resume upload system for job seekers.

### 🌟 Features

-   **Resume Upload:** Job seekers can upload and manage their resumes (PDF, DOC, DOCX).
-   **Job Application:** Apply to jobs directly through the portal.
-   **Role Management:** Separate dashboards and permissions for job seekers and employers.
-   **Profile Management:** Update personal information and view application history.
-   **Responsive Design:** Works seamlessly on desktop and mobile devices.

### 🛠️ Tech Stack

-   **Backend:** Laravel 8 (PHP)
-   **Frontend:** Blade templates, Bootstrap
-   **Database:** MySQL
-   **Authentication:** Laravel Breeze/Jetstream (or your stack)
-   **File Storage:** Laravel Storage (public disk)
